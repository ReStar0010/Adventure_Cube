**第一步：執行亂數生成 (RNG)**
請在腦中為每個類別擲一個骰子，並輸出結果：

**第二步：根據亂數查表 (Lookup Table)**

**1. 抽選任務 (Quest Mode) - 對應 Quest_Roll:**
   * **[1] -> [尋寶任務]**：目標是找回遺失物（如：國王的假牙、月球鑰匙）。
   * **[2] -> [發明任務]**：目標是組裝或修理機器（如：自動餵龍機、星星捕捉網）。
   * **[3] -> [捷徑任務]**：目標是快速到達某處（如：趕去參加晚宴、爬上最高的樹）。

**2. 抽選誤用 (Misuse) - 對應 Misuse_Roll (根據道具二選一):**
   * *若為羅盤*：
     - **[1] -> [金屬探測器]**：不看方向，把它貼在地上掃描寶藏。
     - **[2] -> [迴力鏢]**：把它當作投擲武器，想把高處的東西打下來。
   * *若為羽毛筆*：
     - **[1] -> [撬棍]**：把它當作螺絲起子或棍子，用力撬開箱子。
     - **[2] -> [指揮棒]**：把它當作魔法指揮棒，揮舞著指揮傢俱移動。

**3. 抽選制伏方式 (Climax Action) - 對應 Climax_Roll:**
   * **[1] -> [捕捉]**：拿出網子、帽子或袋子，像抓蝴蝶一樣精準地套住道具。
   * **[2] -> [卡住]**：引導道具衝進一個狹窄的縫隙（或黏黏的果凍裡），讓它動彈不得。
   * **[3] -> [安撫]**：(筆) 給它一張巨大的白紙讓它寫個夠；(羅盤) 丟給它一顆真的糖果讓它停下來吃。

**4. 抽選解決方式 (Resolution Type) - 對應 Resolution_Roll:**
   * **[1] -> [物理撞擊]**：亂飛的零件/道具剛好撞進了正確的位置（喀嚓一聲修好了/打開了）。
   * **[2] -> [痕跡揭示]**：道具在牆上亂畫的塗鴉，退後一步看，竟然是一張藏寶圖或解謎關鍵。
   * **[3] -> [視角轉換]**：雖然沒到達原本的目的地，但被彈飛到了更高的地方，反而看到了更棒的景色（或原本找不到的路）。

**第三步：輸出最終設定**

魔法城堡裡的地毯，每天早上都會伸個懶腰，發出像小貓一樣的呼嚕聲，提醒大家起床啦！今天，呼呼（有鱗的愛哭鬼）和鏘鏘（沉穩的冒失鬼）正要趕去參加城堡最高的瞭望台上舉辦的下午茶會。可是，城堡裡的樓梯今天特別調皮，一直換來換去，害他們怎麼也上不去。鏘鏘拍拍胸脯：「別擔心！我有秘密武器！」他拿出了貪吃的羅盤，得意地說：「用它當金屬探測器，一定能找到通往瞭望台的黃金捷徑！」說著，就把羅盤貼在地上，開始左右掃描。

羅盤一接觸地面，就發出「嗡嗡嗡」的抗議聲，指針開始瘋狂旋轉！原來，羅盤以為地面上有好多好多糖果！它「咻」的一聲掙脫了鏘鏘的手，鎖定了一隻在窗邊飛舞的蒼蠅，拖著他們在城堡裡橫衝直撞！「啊！我的下午茶！」呼呼嚇得哇哇大哭，眼淚像斷線的珍珠一樣往下掉。羅盤拉著他們，先是撞倒了一堆盔甲，盔甲們像疊疊樂一樣「匡啷匡啷」倒了一地。接著，又撞翻了裝滿彩色果凍的推車，果凍像海浪一樣湧了出來，城堡頓時變成了一個黏糊糊的遊樂場！

在混亂的追逐中，他們不小心撞到了一幅掛在牆上的畫像。畫像裡的國王鬍子一翹，竟然啟動了一個隱藏的機關！「咚！」的一聲，城堡開始震動，他們腳下的地板突然傾斜，像雲霄飛車一樣！眼看羅盤就要撞上牆壁了，呼呼靈機一動，從口袋裡掏出一顆糖果。「糖果！給你！」他把糖果塞進羅盤的大嘴巴裡。羅盤立刻安靜了下來，津津有味地啃著糖果。

兩人連同羅盤，一起像溜滑梯一樣滑了出去，「砰」的一聲，摔進了一個堆滿羽毛枕頭的房間。呼呼揉著摔疼的屁股，正要哭出來，突然發現窗外的景色不一樣了！原來，他們雖然沒有到達原本的瞭望台，卻被彈到了城堡最高的尖塔上！從這裡看出去，整個甜點小鎮都盡收眼底，比瞭望台的風景還要棒！羅盤也吃完了糖果，乖乖地指向遠方。呼呼破涕為笑：「哇！這裡的風景更漂亮！」鏘鏘也鬆了一口氣，拍拍羅盤說：「這次雖然幫了倒忙，不過結果還不錯嘛！」他們在尖塔上，一邊欣賞美景，一邊享用遲來的下午茶，城堡裡迴盪著他們的笑聲。
